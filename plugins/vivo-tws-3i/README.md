# vivo TWS 3i 电量插件

**只读**插件：通过 BLE 广播被动监听读取 vivo TWS 3i 的左耳 / 右耳 / 充电盒电量。

- 插件 id：`vivo-tws-3i`
- 传输方式：`ble-advertisement`（被动扫描，不连接、不写入）
- 验证状态：`captured`（有可重复原始样本 + 双通道交叉验证；**尚未**与官方 App 显示值交叉验证）

## 工作原理

耳机通过 Fast Pair 厂商数据段（CompanyId `0x0837`）周期性广播自身状态。
本插件只监听这些广播，解析其中的电量字段。

广播载荷结构（Windows 已剥离 CompanyId，偏移相对载荷起点）：

| 偏移 | 含义 |
| --- | --- |
| `[0]` | 广播类型，`0x08` = TWS 对类 |
| `[1]` | 格式版本，`0x01` = V1（本插件支持） |
| `[2..7]` | 设备 MAC（**已脱敏**） |
| `[8]` | 状态字节：低 3 位在盒状态（bit0 左耳在盒 / bit1 右耳在盒 / bit2 基座闭合），高 2 位 `mPairState` 连接状态 |
| `[9]` | **充电盒电量 %** |
| `[10]` | **右耳电量 %** |
| `[11]` | **左耳电量 %** |
| `[12]` | 充电状态：bit0 左充 / bit1 右充 / bit2 盒充 |
| `[13]` | 型号 id（TWS 3i = 132 / 133） |
| `[14..17]` | 未确认字段 |

## 身份判定

以**广播中的 model id**（`[13]`）为主要依据，不以产品名匹配——官方 App 的
`assets/tws_config.json` 给出 TWS 3i = model `132` / `133`，project `DPD2407A`。

同系列长续航版为 model `144` / `145`（`DPD2407AC`），属**另一个型号**，
按「每型号独立验证」原则，在取得实测样本前**不在支持列表内**。

## 已知限制

- **充电盒电量**依赖广播 `[9]` 字段；部分固件可能不提供（`0xFF`），此时显示未知，**不显示 0%**。
- 广播格式随代际演进（TWS V1 / V2 / Advertise / 单耳类）。本插件**只实现 V1**，
  遇到其他格式会明确拒绝并给出诊断，不会误读。
- 同一区域内可能存在非 TWS 格式的 `0x0837` 广播（如 `payload[0]=0x85`），
  解析器会拒绝。
- 广播里的连接状态位只表示「耳机连着某个客户端」，**不区分连接对象**，
  也不影响电量可读性（双连接下电量照常可读）。
